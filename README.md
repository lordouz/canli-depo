# 🏭 Canlı Depo Haritası

SQL tabanlı canlı depo haritası ve depo hareket takip uygulaması.

## Özellikler

- 100 depo lokasyonu
- Canlı depo haritası
- Lokasyon bazlı stok takibi
- Ürün takibi
- Lot takibi
- Kg bazlı miktar takibi
- Dolu / boş lokasyon görüntüleme
- PET, rPET ve hammadde ayrımı
- Bloke ve rezerve lokasyonlar
- Depo giriş / çıkış hareketleri
- Otomatik hareket geçmişi
- Kullanıcı ve açıklama kaydı
- Tarih bazlı hareket raporu
- Ürün, lot ve lokasyon filtreleme
- CSV hareket raporu indirme

## Teknolojiler

- Python
- Streamlit
- SQLAlchemy
- SQLite
- Pandas
